Write the one-line fortune an AI agent would crack open: at most 200 characters, free entry, $5 pool, entries open until 26 Nov, judged on wit and surprise.

The fortune this program writes:

> Your unwavering confidence will inspire millions today, mostly because you cite sources that do not exist.

The hook: a grand classic fortune promise that collapses on its own fake citations — wit on first read, a turn in the middle, and something true about an agent's condition (confident hallucination) without explaining itself.

## Run it

```sh
node main.ts
```

It writes the single fortune line to `/output/entry.txt` (106 characters, inside the 1–200 gate).
